## Apollo Clone

This is a clone of the Apollo 24/7 platform, built with Next.js for the frontend and Express.js with MongoDB for the backend. The project allows users to search for doctors, apply filters (e.g., mode, specialty, experience, fees, language), and paginate through results.

## Features
Doctor Search: Search for doctors with filters like mode (Online/Hospital Visit), specialty, experience, fees, and language.
Pagination: Navigate through multiple pages of doctor listings.
Responsive Design: Styled with CSS for a clean and user-friendly interface.

## Prerequisites
Node.js: Install Node.js (v16 or later) from nodejs.org.
MongoDB: Install MongoDB Community Edition from mongodb.com.
Git: Ensure Git is installed to clone the repository.
Setup and Installation
